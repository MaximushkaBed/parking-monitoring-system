# Parking System Web Interface

Простой функциональный веб-интерфейс для системы мониторинга парковок.

## Возможности

✅ **Управление камерами**
- Добавление RTSP/HTTP камер
- Просмотр статуса (online/offline)
- Live preview кадров
- Удаление камер

✅ **Калибровка камер**
- Выбор контрольных точек на кадре
- Выбор соответствующих точек на схеме
- Автоматическое вычисление homography матрицы
- Визуальная проверка калибровки

✅ **Редактор парковочных мест**
- Рисование прямоугольников и полигонов
- Типы мест: обычное, инвалид, семейное, VIP, электро, краткосрочная
- Выбор и удаление мест
- Сохранение в базу данных

✅ **Live мониторинг**
- Текущая загрузка парковки в реальном времени
- Статистика: всего/занято/свободно/% загрузки
- Список всех мест со статусами
- Авто-обновление каждые 2 секунды

✅ **Аналитика**
- История загрузки (день/неделя/месяц)
- Список аномалий (долгостоящие авто >24ч)
- Экспорт отчетов в PDF

## Установка и запуск

### 1. Запустить Python backend

```bash
cd backend
python3 main.py
```

Backend будет доступен на `http://localhost:8000`

### 2. Запустить веб-интерфейс

Просто откройте `frontend/index.html` в браузере.

Или используйте простой HTTP сервер:

```bash
cd frontend
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в браузере.

### 3. Настройка

Если backend запущен на другом хосте/порту, отредактируйте `frontend/js/config.js`:

```javascript
const CONFIG = {
    API_BASE_URL: 'http://your-server:8000/api',
    ...
};
```

## Использование

### Шаг 1: Добавить камеры

1. Перейдите на вкладку "Камеры"
2. Нажмите "+ Добавить камеру"
3. Введите название и RTSP URL (например: `rtsp://admin:password@192.168.1.100:554/stream`)
4. Выберите тип камеры (RTSP/HTTP/Motion Activated)
5. Нажмите "Добавить"

### Шаг 2: Калибровать камеры

1. Перейдите на вкладку "Калибровка"
2. Выберите камеру из списка
3. Загрузите схему парковки (изображение)
4. Кликните 4-8 точек на кадре камеры
5. Кликните соответствующие точки на схеме
6. Нажмите "Вычислить калибровку"

### Шаг 3: Нарисовать парковочные места

1. Перейдите на вкладку "Редактор мест"
2. Выберите камеру
3. Загрузите схему парковки
4. Выберите инструмент (прямоугольник или полигон)
5. Выберите тип места
6. Нарисуйте места на схеме
7. Нажмите "Сохранить все"

### Шаг 4: Мониторинг

1. Перейдите на вкладку "Мониторинг"
2. Включите авто-обновление
3. Наблюдайте за статусом мест в реальном времени

### Шаг 5: Аналитика

1. Перейдите на вкладку "Аналитика"
2. Выберите период (день/неделя/месяц)
3. Просмотрите историю и аномалии
4. Экспортируйте отчет в PDF

## Технические детали

## Troubleshooting

**Ошибка CORS:**
- Убедитесь, что backend настроен с правильными CORS заголовками
- В `backend/main.py` должен быть `CORSMiddleware` с `allow_origins=["*"]`

**Камера не подключается:**
- Проверьте RTSP URL
- Убедитесь, что камера доступна из сети
- Проверьте логи backend

**Калибровка не работает:**
- Нужно минимум 4 точки на каждом изображении
- Точки должны соответствовать друг другу по порядку
- Проверьте качество кадра с камеры
